- [ ] **Queue triage (Greg Isenberg, https://www.youtube.com/watch?v=4mTLpuQpB80).** Angle: every business has an expensive queue (email, leads, support); put a decision model at the front, act on the confident calls, send the unsure middle to an LLM or a person, drop the rest. That is full automation with confidence, not "AI that someone checks". Creator numbers: 1,700 emails scored, about 200 ms a decision. His own limit: weak on buy/sell calls, so advise, don't decide, on high stakes. Find a named company with a triage result at scale.
- [ ] **Which decision model for the job (Better Stack, https://www.youtube.com/watch?v=Uihz1NkhFM0, article https://betterstack.com/community/guides/ai/jev-vs-clef-decision-model/).** Angle: decision models are now a category; test on your own data before you pick. Jev vs Cloudflare Clef on 200 real comments, graded by Opus 5.5: 86% vs 83% overall, Jev about 6.5x cheaper and 2x faster; Jev won tone (75% vs 49%), Clef won toxicity (88% vs 81%), reads images and has open weights. One test, one grader: label it. Ties into the category plan (decision-model-category memory).
- [ ] **Let the agent act, behind a gate (Raj Kapadia, https://www.youtube.com/watch?v=jU6o3nUY17s, code https://github.com/RajKKapadia/youtube-typesafe-ai-demo).** Angle: no one automates and then reviews by hand; an agent proposes an action, the decision model scores it (matches the request? authorized? reversible? risky? breaks policy?), code allows, escalates or blocks. Puts a number on the risk before anything happens. No accuracy figures in the video: pair with Datadog (scores agent shell commands before they run) and Harness's agent-governance post.
- [ ] **Where a decision model fits: one ticket, three questions (Yash Thakker, https://www.youtube.com/watch?v=im_hLbl6ldU, repo https://github.com/whyashthakker/awesome-jev-use-cases).** Angle: a leader's map of where to couple; one support ticket asks which team (choice), does it want a refund (yes/no), how frustrated (score), then code combines them. 50 demos vs gpt-4o-mini; preview numbers are made up, so no results claimed. Lesson: 0.5 means unsure, not medium; one question per condition.
- [ ] **Decision model plus coding agent (Ray Amjad, https://www.youtube.com/watch?v=ScvXFi4MUSc).** Angle for engineering leaders: the decision model makes the fast gut calls inside a coding agent (which skill, is this error worth waking someone, is this a code smell, Sentry triage, review), Claude does the reasoning. Only a chapter list so far: needs the most research; find a named team with numbers.
